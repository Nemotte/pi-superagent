# Web 提交无反馈修复

## 现场证据

用户反馈点击“提交给 Router”没有反应。只读检查既有实例的本地 API：已有两条 manual Trigger，零 Ticket/Decision；paused=true，routerModel/workerModel 均为 null。POST 已持久接收，派单尚未启动。现有前端成功后仅清空输入并刷新工单列表；暂停或 Router 尚未接单时，列表为空且没有提交回执。

## 修复范围

选择表单就近回执与常驻阻塞说明，而非短暂通知或自动恢复派单。

- 工单提交区显示当前暂停/模型未配置的原因，提供 `/superagent setup` 指引；状态随现有轮询更新。
- 提交中禁用按钮和输入，防止重复点击，显示进行中；请求有 10 秒截止。
- API 接收成功即显示持久请求 ID，不将后续状态刷新失败误报为提交失败。Router 接单后的 Ticket 仍由原有列表展示。
- 失败/响应丢失显示“结果未确认”，保留文本和幂等 ID；用户手动重试同样文本复用 ID，不自动重试。
- “查看已提交请求”打开现有 Trigger 记录视图，刷新页面后仍可找到请求，不需要重新提交。不把任务正文写入浏览器存储。
- 不修改后台派单语义，不自动选择模型、登录、probe、恢复派单或重启用户实例。静态 Web 文件刷新即可加载。
